# Nmap Reconnaissance Project

## Overview
Performed reconnaissance on a target machine using Nmap in a TryHackMe lab environment.

## Scans Performed
- Basic Scan: nmap <target-ip>
- SYN Scan: nmap -sS <target-ip>
- TCP Connect Scan: nmap -sT <target-ip>
- UDP Scan: nmap -sU <target-ip>
- Version Detection: nmap -sV <target-ip>
- OS Detection: nmap -O <target-ip>
- Aggressive Scan: nmap -A <target-ip>
- Script Scan: nmap --script vuln <target-ip>

## Tools Used
- Nmap
- TryHackMe Lab
- Linux

## Findings
- Identified open ports and running services
- Identified OS and service versions
- Documented results for further analysis
